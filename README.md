# SFML-WhiteBoard-with-WebSockets

Интерактивная доска для рисования с использованием библиотеки SFML и возможностью подключения по WebSockets.

## Функциональность
- Рисование с помощью мыши (левая кнопка)
- Плавные линии с промежуточными точками
- Очистка холста (клавиша C)
- Отображение FPS в реальном времени
- Ограничение количества элементов для оптимизации производительности

## Технологии
- SFML 2.5 (графика, окно, система)
- C++17
- CMake для сборки

## Запуск

1. В основной папке написать команду:

```bash
cmake .
```

2. Перейти в создавшуюся папку `build`

3. Написать в этой папке команду:

```bash
make all
```

4. В папке build появится исполняемый файл `WhiteBoard`
